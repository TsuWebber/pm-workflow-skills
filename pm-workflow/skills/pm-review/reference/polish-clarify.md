# clarify：統一用語、消除模糊詞

處理「字面上看得懂，但不同人會讀出不同意思」的問題。
不改結構、不增刪功能，只改用詞。

輸入：Notion URL、本機檔案，或對話中的內容。

---

## 檢查項目

1. **系統與通路名稱**：依 CLAUDE.md 統一（OMS / 經銷商平台 / 2B / 2C / CMS / 庫存工具）。同一份文件第一次出現時可寫全名加代稱，例：「OMS（OMS）」，之後統一用代稱。
2. **同義詞混用**：同一概念出現兩個以上說法（例：銷退 / 退貨 / 退回），選一個並全文統一；若兩個詞其實是不同概念，補一句定義區分。
3. **專案特有名詞**：對照 `.pm/PROJECT.md`「名詞補充」；新出現且會反覆使用的名詞，建議加進 Definitions 區段與 PROJECT.md。
4. **模糊詞**：`../../../shared/floor.md` §6、§7 的模糊詞與空話，改成具體條件或數字；無法具體化的改成 `🟡 待確認`。
5. **主詞不明**：「需要確認」「會通知」「要處理」沒寫誰 → 補上角色或部門。
6. **相對時間**：「近期」「之後」「盡快」→ 改成具體日期或觸發條件。

---

## Output Format

```
## Clarify：[文件名稱]

### 用語統一
| 原用詞 | 統一為 | 出現位置 |
|---|---|---|
| 退回、銷退 | 退貨 | A-1、A-3 |

### 逐句修改
| 位置 | 原文 | 修改後 | 原因 |
|---|---|---|---|
| A-2 | 必要時通知客服 | 退款失敗時通知客服 | 模糊詞，補判斷條件 |

### 建議新增定義
- [名詞]：[一句話定義]
```

使用者確認後再輸出套用修改的完整版本；寫回 Notion 需另外明確指示。
