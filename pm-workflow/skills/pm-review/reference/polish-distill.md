# distill：壓縮冗長內容

把文件壓到「讀者需要的最少字數」，**不刪任何決策、規則、數字或待確認項目**。

輸入：Notion URL、本機檔案，或對話中的內容。可指定只壓某一段。

---

## 可以刪 / 合併的

- 同一件事在兩處重複描述 → 留在最該出現的位置
- 功能概述已說清楚、子主題又換句話說一次 → 刪子主題的重述
- 「本功能的目的是為了…」「需要注意的是…」等鋪陳句 → 直接講內容
- 新增 / 編輯 / 刪除 / 排序屬同一組管理能力 → 合併成一條
- 討論語氣、背景故事（Build / Announce mode 文件）→ 移到 Discussion 區段或刪除
- 沒內容的段落 → 刪除

## 不可以刪的

- 任何規則、判斷條件、數字、上下限
- `🟡 待確認` 項目
- 條件分支（若 A 則 X）
- Scope 的排除項
- 連結與來源

---

## Output Format

1. 給出壓縮後的完整版本。
2. 結尾附一行：`原 N 字 → 現 M 字（-X%）`。
3. 若有刪除的內容可能被質疑，列出「刪除項目」1–3 條供使用者確認。

不寫回 Notion，除非使用者明確指示。
