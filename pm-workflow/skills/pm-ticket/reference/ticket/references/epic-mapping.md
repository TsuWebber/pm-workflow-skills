# Epic 對照表（範例）

> 這份是範例模板。實際使用時，換成你們 Jira 專案的 Epic 清單。

## 判斷原則

選 Epic 看的是問題的**根本原因所在模組**，不是症狀表現的模組。
- 匯入 ERP 失敗，根因是 OMS 訂單資料不齊全 → **OMS（PROJ-102）**
- 匯入 ERP 失敗，根因是 ERP 匯入邏輯本身 → **ERP 整合（PROJ-103）**

## 主要 Epic 清單

| 模組 | Epic Key | 典型票類型 |
|------|---------|-----------|
| 官網 | PROJ-101 | 前後台 bug、結帳、購物車、商品頁 |
| OMS | PROJ-102 | 訂單資料、出貨、退貨流程 |
| ERP 整合 | PROJ-103 | 匯入失敗、對帳差異 |
